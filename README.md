# Pixtorium Homebrew tap

```
brew install --cask yovico-ai/tap/pixtorium
```

Installs Pixtorium (https://pixtorium.com), an approachable, AI-native image
editor, on Apple Silicon Macs. The cask also puts `pixtorium-mcp` on your PATH.
The app is not notarized yet, so the cask clears macOS's quarantine mark.

This repository holds the cask only; it is updated at each release.
